# Алматы рядом — MVP ИИ-гида

## Решения и границы

Аудитория: туристы и местные жители. Адаптивный веб-сайт, русский интерфейс; будущие kk/en словари подключаются через `src/i18n.js` (при добавлении перевода нужно вынести оставшиеся подписи из компонентов). Без регистрации, сохранения аккаунтов, бронирования и оплаты. React/Vite + Express, Leaflet/OpenStreetMap, JSON-каталог без базы данных.

Пользователь выбирает интересы, время, бюджет, старт из каталога или геолокацию и способ перемещения. Сервер последовательно выбирает подходящие точки, учитывая время посещения и перемещения, плановый бюджет и интересы. Показываются причины выбора, порядок точек, переходы и источники. Гид знает актуальные ограничения; локальные команды «сделай короче», «бесплатно», «больше природы», «убери [полное название]» реально пересчитывают маршрут. Свободные вопросы без ключа обрабатываются шаблонным демо-гидом, а не языковой моделью.

## Запуск

Node.js 24, npm. Из корня проекта:

```sh
npm ci
npm test
npm run dev
```

Сервер слушает порт 3000. `PORT` позволяет изменить порт. Для production: `npm run build`, затем `npm start`. Хостинг должен поддерживать Node.js, HTTPS (для геолокации вне localhost), исходящие HTTPS-запросы и передачу переменных серверному процессу. Файлы `dist` не содержат серверных ключей. В облачных задачах используйте существующий checkout, не создавайте worktree без явной просьбы.

Проверки: `npm test` — 7 тестов расчёта и гида; `npm run build` — сборка клиента. `node scripts/smoke.mjs` — браузерный сценарий с Chromium, API, картой и мобильной шириной. По умолчанию Chromium `/usr/bin/chromium`; задайте `CHROMIUM_PATH` для другой установки. Сначала запустите сервер, `TEST_URL` меняет адрес для проверки.

## ИИ и ключи (необязательно, платно)

При бюджете 0 ключ не нужен. Если позже понадобится настоящий ИИ, передайте серверному процессу `GUIDE_API_KEY` через защищённые настройки хостинга. `GUIDE_MODEL` по умолчанию `gpt-4o-mini`. Не добавляйте ключ в клиент, переменные `VITE_*`, Git или текст чата. Локально можно использовать игнорируемый `.env` с `GUIDE_API_KEY=...` и `GUIDE_MODEL=gpt-4o-mini`; Node загружает его при старте. `.env.example` содержит только имена, без значений ключей.

Используется серверный POST `https://api.openai.com/v1/chat/completions`, таймаут 15 секунд, до 500 токенов ответа. При 429, таймауте или другой ошибке — демо-ответ с предупреждением. Контекст ограничен текущим маршрутом и каталогом; история диалога не отправляется. Ответы модели не изменяют фактический каталог и не управляют маршрутом. Системная инструкция запрещает дополнять факты; это снижает риск выдумок, но не гарантирует их отсутствие, поэтому все ответы модели отдельно помечаются. Живой OpenAI-вызов без ключа не проверен.

В managed cloud секрет GUIDE_API_KEY следует привязать к `api.openai.com` через настройки среды. Для стандартного хостинга используйте его серверные secrets. Не заменяйте системные прокси и не отключайте TLS.

## Данные: заменить демо реальными

`data/places.json` — единственный каталог. Все текущие записи демонстрационные: координаты приблизительны, сведения не проверены, `verifiedAt: null`. Ссылки OSM помогают найти место, но не доказывают проверку. Часы, адреса, исторические факты и цены входа намеренно отсутствуют. `summary` — редакционная рекомендация, не ответ ИИ. `visitMinutes` и `planningCost` — предположения для планирования, не фактическая длительность и не тариф.

Для обновления: проверьте каждую запись по официальному сайту/управляющей организации и карте; внесите точные координаты, источники и дату проверки; подтвердите условия посещения. Сохраняйте стабильные `id`, поля `tags` из `server/planner.js`, минуты и неотрицательную оценку расходов. После изменения запустите тесты и сборку, перезапустите сервер. При переходе к проверенным данным расширьте схему отдельными источником и датой для каждого факта, обновите демо-маркировку UI и тексты неопределённости; одного заполненного verifiedAt недостаточно. Админ-панель/автообновление пока не реализованы.

## Ограничения и устойчивость

- Время: расстояние по прямой × 1.35, 4.5 км/ч пешком или 18 км/ч + 8 минут ожидания для транспорта на каждый участок. Для транспорта заложены 300 ₸ на участок: это допущение, не действующий тариф. Нет дорог, расписаний, пробок, доступности переходов, возврата к старту и глобальной оптимизации.
- Для еды заложен необязательный план расходов 2000 ₸. Другие точки предполагают осмотр снаружи без покупки билетов. Нулевой бюджет не гарантирует бесплатный доступ.
- Карта использует публичные OSM tiles, сохраняет атрибуцию, без массовой загрузки. Для публичного запуска необходимо проверить tile usage policy, нагрузку и выбрать подходящего tile-провайдера. Подложка требует сети; при её сбое остаются список, маркеры и схема порядка точек, есть предупреждение.
- Геолокация требует разрешения; при ошибке, низкой точности или старте вне Алматы предлагается ручной выбор. Координаты отправляются только серверу расчёта и при ИИ-вопросе как часть маршрута; постоянного хранения и аналитики нет.
- Валидируются параметры, размер JSON ограничен 16 КБ, 40 API-запросов в минуту на IP (in-memory). При production за прокси нужно настроить доверенные прокси, устойчивый rate limiting и ограничения расходов провайдера. Это демонстрационный, не промышленный антиабьюз.
- Пустые маршруты и ошибки API отображаются. Изменение формы применяется кнопкой «Составить маршрут»; чат работает с уже рассчитанным маршрутом.

## Три следующих улучшения

1. Проверенный каталог с источниками на уровне фактов и процессом обновления.
2. Дорожный routing API для пешеходов/транспорта и реальная оценка доступности маршрута.
3. Полные kk/en переводы и более гибкий ИИ-диалог с подтверждаемыми изменениями маршрута, лимитами затрат и сохранением прогулки.

## Результаты проверки в этой облачной среде

- Чистая установка `npm ci` из lockfile, 7/7 тестов, production-сборка — успешно.
- Chromium: создание маршрута, сокращение времени, нулевой бюджет, popup выбранной точки, мобильная ширина 390 px, отказ некорректного API-ввода — успешно; JavaScript-ошибок нет.
- Dev-сервер порт 3000 и production-сервер порт 3001 запущены. Процессы нужно запускать снова в новой задаче.
- Подложка OSM сейчас недоступна: запрос тайла через прокси получает HTTP 403. Подтверждён режим деградации со списком, точками и предупреждением. Разрешение `tile.openstreetmap.org` сохранено в черновике среды; применение и повторная проверка ещё нужны.
- Серверное подключение OpenAI реализовано, но реальный запрос не выполнялся: ключ не настроен, выбран бюджет 0. Проверен демо-режим и fallback при ошибке провайдера.
- Публикация среды и развёртывание на публичном хостинге не выполнялись.

## Городской квест

На главной странице по умолчанию открыт режим «Квест по городу». Подбор персональной прогулки доступен на соседней вкладке. Первый маршрут: парк панфиловцев → Вознесенский собор → Зелёный базар → Арбат. Остановки открываются по порядку после правильного ответа. Прогресс хранится в localStorage этого браузера (ключ `almaty-city-quest-v1`), без регистрации и синхронизации между устройствами. За этап начисляется 100 баллов, при использовании подсказки — 70. Геолокация не подтверждает присутствие игрока; ответы проверяются локально. Квест — стартовая версия для редакторской проверки гидом перед коммерческим запуском.

### Видео и аудио об объектах

Записи не включены в проект. Чтобы добавить их, заполните `data/quest-media.json` для соответствующей остановки:

- `video`: адрес MP4/WebM или путь `/media/cathedral.mp4`;
- `audio`: адрес MP3 или путь `/media/cathedral.mp3`;
- `captions`: адрес файла субтитров WebVTT;
- `transcript`: текстовая расшифровка рассказа.

Локальные медиафайлы кладите в `public/media/`. Используйте прямые ссылки на файлы, а не страницы YouTube. Плееры запускаются вручную, без автозагрузки записи. При отсутствии файла выводится честное сообщение, при ошибке загрузки можно продолжить по тексту. Используйте записи, на публикацию которых есть права. Содержание исторических рассказов нужно проверить перед добавлением.

Проверка логики квеста: `node --test tests/quest.test.js`.
