# Как получить публичную ссылку на «Алматы рядом»

Для первой публикации выбрана бесплатная веб-служба Render. Приложение имеет сервер на Node.js, поэтому обычный статический хостинг не подходит: он не запустит расчёт маршрута и чат. `render.yaml` содержит команду установки и сборки, запуск, проверку здоровья и бесплатный план. Ключ ИИ для первой публикации не нужен.

## Что уже готово

- Адаптивный интерфейс и серверный API.
- Команды `npm ci`, `npm test`, `npm run build` и `npm start`.
- Проверка сервиса `/api/health` для хостинга.
- Ключи не включаются в код сайта или Git. `node_modules`, `dist` и `.env` исключены из Git.

## Пошаговая публикация

1. Сохраните файлы этого проекта в GitHub-репозитории `smirnovaalyona91/my-first-project`. Сейчас изменения в облачном checkout могут ещё не быть отправлены в GitHub. Если вы не видите новый файл `render.yaml` на странице репозитория, напишите в чате: «подготовь коммит и отправку в GitHub». Не создавайте проект заново и не копируйте файлы вручную.
2. Зайдите на https://dashboard.render.com и войдите через GitHub. При первом входе Render попросит разрешить доступ к репозиторию.
3. Выберите **New → Blueprint**. Подключите GitHub-репозиторий `smirnovaalyona91/my-first-project`. Render прочитает `render.yaml` и покажет веб-службу `almaty-ryadom` с планом **Free**. Перед подтверждением убедитесь, что в интерфейсе указан именно бесплатный план и нет платных ресурсов.
4. Подтвердите создание службы. Render установит зависимости, соберёт клиент и запустит сервер. Дождитесь сообщения о успешном развертывании. Ссылка будет вида `https://almaty-ryadom.onrender.com`; используйте фактический адрес из панели Render — имя может отличаться, если занято.
5. Откройте полученную ссылку с телефона или компьютера. Выберите интересы и нажмите «Составить маршрут». Проверьте, что появились остановки и точки на карте. Затем нажмите «Сделай короче» в чате. Откройте `<ваш-адрес>/api/health`: ожидается JSON `{"ok":true,"guideMode":"demo"}`.

На бесплатном плане служба может засыпать при отсутствии посещений; первый запрос после паузы запускается дольше. Доступность бесплатного плана и условия Render могут измениться — перед созданием проверьте условия в его интерфейсе. Демо-гид бесплатен; настоящий ИИ оплачивается отдельно и не включён в конфигурацию.

## Если что-то не работает

- Страница открывается, но маршрут не создаётся: откройте `/api/health` и проверьте, что служба в состоянии Live. Посмотрите **Logs** в Render.
- Подложка карты отсутствует: список маршрута и точки остаются доступны. Проверьте сеть браузера и доступность `tile.openstreetmap.org`. Для публичной нагрузки потребуется отдельный tile-провайдер с подходящими условиями.
- `Build failed`: проверьте, что `package-lock.json` попал в GitHub и команда Build в Render равна команде из `render.yaml`.
- `Application failed to start`: проверьте журнал Render, версию Node 24 и команду Start `npm start`.

## Позже: включить настоящий ИИ

Если решите использовать платный API, добавьте `GUIDE_API_KEY` как **secret environment variable** веб-службы Render. Не помещайте его в GitHub и не используйте префикс `VITE_`. При необходимости добавьте `GUIDE_MODEL`. Установите лимиты расходов у провайдера. После перезапуска `/api/health` покажет `guideMode: "ai"`. Сам ответ ИИ всё равно следует проверять по источникам.
