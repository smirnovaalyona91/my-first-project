# my-first-project

## Алматы рядом — ИИ-гид по Алматы

Работающий демонстрационный MVP для туристов и местных жителей: персональный маршрут, интерактивная карта, карточки остановок и гид с командами изменения прогулки.

```sh
npm ci
npm test
npm run dev
```

Node.js 24, порт 3000. Ключи не нужны для демо. Production: `npm run build` и `npm start`.

Подробности запуска, настройки серверного ИИ, источников данных, допущений и ограничений — в [DEVELOPMENT.md](DEVELOPMENT.md).
